# Наблюдение за браузером Ozon

В разделе Ozon пункт «Браузер Ozon» открывает `/ozon/browser`. Страница показывает,
запущен ли серверный Chrome, идёт ли сбор, адрес и заголовок открытой страницы,
состояние загрузки и последний кадр с временем получения по Москве. Это просмотр:
нажатия не передаются в Chrome, страница не перезагружается, размер окна не меняется.
Если Chrome закрыт, просмотр не запускает его.
При запуске браузерная служба сразу открывает избранное Ozon с сохранённым профилем.
Сборщик цен при этом не вызывается: страница просто загружается для просмотра,
а записи цен и расписания не меняются. Первый сбор использует эту же вкладку,
не создавая вторую и не перезагружая уже открытую страницу избранного. Во время
простоя служба не выполняет повторных переходов и перезагрузок. Если Ozon покажет
ошибку или запрос входа, просмотр отображает фактическое содержимое страницы.
Пустая вкладка `about:blank` тоже может быть показана как фактическое состояние,
но ожидать первого сбора для открытия Ozon больше не нужно.

Кадры запрашиваются раз в 5 секунд только при открытой видимой вкладке.
Автообновление можно приостановить и получить кадр кнопкой «Обновить».
Во время сбора новые команды наблюдения не отправляются: показывается состояние
«Идёт сбор» и, если он есть, ранее полученный кадр с исходным временем.
Снимки текущего состояния не пишутся на диск; временный серверный кеш удаляется
через 15 секунд без новых снимков. Одновременные просмотры используют общий кадр.

При ошибке чтения избранного или начальной загрузки страницы сборщик один раз
пытается получить снимок. Он заменяет предыдущий в приватном файле
`price-checker-browser-error.json` внутри существующего Chrome-профиля, с правами
0600. Файл хранит только время, категорию ошибки, HTTP-статус, заголовок, адрес без
query/hash и один JPEG размером до 2 МиБ в base64. Cookies и ответы API туда не
записываются. Снимок может содержать персональные данные, видимые на странице Ozon,
поэтому доступ к нему защищён входом Price Checker. Сам файл не включается в Git.
Неответивший или уже закрытый браузер может оставить запись ошибки без изображения.
Снимки сбоев до установки этой функции отсутствуют.

Окно интерактивного входа не снимается. Во время входа здесь отображается только
его состояние; владелец продолжает вход на защищённой странице `/ozon/login`.

GET `/api/providers/ozon/browser` требует настоящую сессию Price Checker даже при
отключённой авторизации остальных разделов. Ответы имеют `Cache-Control: no-store`.
Фронтенд не сохраняет кадры в browser storage и удаляет кеш при выходе из аккаунта
или уходе со страницы. Монитор использует отдельный Unix-сокет
`/run/price-checker-ozon-monitor/view.sock`, который создаёт уже работающая служба
`price-checker-ozon-recovery.service`. Он принимает только команду наблюдения и не
активируется systemd по запросу. Права 0660 разрешают доступ ozonbrowser и группе
pricechecker; внешний доступ к Chrome/CDP не открывается.

При установке обновления нужно один раз применить шаблон службы с
`RuntimeDirectory=price-checker-ozon-monitor` и перезапустить браузерную службу,
предварительно дождавшись завершения сбора и входа. Штатный
`scripts/setup-ozon-recovery.sh <существующий профиль>` устанавливает этот шаблон,
сохраняя профиль, настройки браузера и расписания магазинов.
