# Управление узлами VPN Ozon

Серверный Codex работает в `/opt/price-checker/repository` и читает инструкции из `AGENTS.md`. Для него доступна команда `python3 scripts/ozon-vpn.py`: каталог всех узлов UN1 и WASP, проверка без обращения к магазинам и переключение по запросу владельца. Сама настройка каталога не меняет основной узел WASP `95.56.251.12`.

## Список и обновление

```sh
cd /opt/price-checker/repository
python3 scripts/ozon-vpn.py list
python3 scripts/ozon-vpn.py list un1
python3 scripts/ozon-vpn.py list wasp
python3 scripts/ozon-vpn.py refresh
```

Список содержит название, тип, сервер, порт, результат последней проверки и два способа выбора: `un1:2` / `wasp:8` или постоянный ID вида `wasp-<hash>`. Номер соответствует порядку в последнем ответе подписки; после обновления он может измениться. ID остаётся прежним, если параметры подключения не меняются, даже при переименовании узла.

`refresh` читает обе подписки; `refresh un1` и `refresh wasp` обновляют только выбранную. Каталог публикуется атомарно после успешного получения выбранных подписок. При ошибке прежний каталог остаётся доступным. Обновление не запускает Mihomo, не меняет активную конфигурацию и не обращается к Ozon или Lamoda. При первоначальной настройке 23 октября 2026 подписки вернули 5 узлов UN1 и 13 WASP.

## Проверка и переключение

```sh
python3 scripts/ozon-vpn.py check un1:2
python3 scripts/ozon-vpn.py switch un1:2
```

`check` разрешает IPv4 выбранного узла, сохраняет исходный TLS/Reality servername и запускает отдельный временный Mihomo на свободном loopback-порту. Только HTTPS-запросы к `api.ipify.org` и `ipwho.is` определяют внешний IPv4 и страну. Временный процесс и приватные файлы удаляются также при ошибке. Активный прокси, службы браузера, расписания и данные магазинов не меняются. Доступность узлов провайдера может меняться; результат проверки содержит время её проведения.

`switch` повторяет эту проверку и только после успеха вызывает `setup-ozon-proxy.sh` с полным приватным профилем, выбранным IP и обнаруженной страной. Установщик удерживает блокировки Ozon и общей очереди, проверяет тот же выходной регион на рабочем порту 17891 и откатывает настройку при ошибке. После переключения перезапускается служба браузера Ozon. Вызов `switch` сам не запускает сбор и не меняет расписания, но последующие плановые сборы используют выбранный маршрут. Маршруты других магазинов и Telegram остаются прежними.

Доступны все страны из подписок. Прямой вызов установщика без третьего аргумента по-прежнему проверяет Казахстан; команда каталога передаёт страну, полученную при предварительной проверке. Автоматического переключения или выбора самого быстрого узла нет.

Пример поручения серверному Codex: «Покажи узлы WASP и переключи Ozon на Германию 1. Перед переключением проверь внешний IP и страну, без запросов к магазинам». Если название неоднозначно, нужно выбрать точный узел из списка.

## Приватные файлы

Корневой файл `/etc/price-checker-ozon-proxy/subscriptions.json` содержит записи `un1` и `wasp`, каждая с полем `url`. Адреса подписок задаются только на сервере; файл принадлежит root и имеет права 0600. Полные профили сохраняются в таком же закрытом `catalog.json`. Код, правила и описание формата находятся в Git; URL, UUID, ключи и полное содержимое этих файлов в Git и сообщения не попадают.

Для WASP используется страница подписки с `data-panel`, из которой получается актуальный адрес выдачи Mihomo. HWID вычисляется из постоянного `/etc/machine-id` с прежним префиксом `price-checker:wasp-vpn:`; обновление каталога использует тот же идентификатор устройства.

Прежние приватные `profiles/wasp-kz.json` и `profiles/un1-kz.json` сохраняются для [ручного возврата](ozon-recovery.md#резервный-маршрут-через-un1). Команды каталога запускаются от root и печатают только сведения о выбранном узле и результат нейтральной проверки. Одновременное обновление, проверка или переключение отклоняется блокировкой каталога.
