# Согласованный формат сообщений Telegram

Согласовано с владельцем 19.10.2026. Формат и маршруты кнопок внедрены на проде
19.10.2026 и сохранены в исходниках проекта.

## Общие правила

- Отдельный отчёт на каждую проверку магазина: расписания Randewoo и Ozon независимы.
- Заголовок: эмодзи состояния, кастомный логотип, название магазина, дата и время сбора.
- Дата и время: `19.10, 14:30 МСК`, часовой пояс `Europe/Moscow`.
- В отчёте показывать отдельно количество снижений и количество повышений текущей цены.
- Не перечислять конкретные товары, цены, суммы и проценты изменений.
- Для большого числа изменений использовать тот же компактный формат со счётчиками.
- Не добавлять события первой проверки, новых товаров, изменения только зачёркнутой
  цены, наличия, неизвестной цены, состава избранного и пустого избранного.
- О проблемах сообщать коротко: что случилось, без подробного технического описания.
- В каждом служебном сообщении должна быть кнопка перехода на сайт.
- URL сайта брать из `PRICE_CHECKER_PUBLIC_ORIGIN`, не закреплять адрес сервера в шаблонах.
- В отчётах кнопка ведёт в раздел соответствующего магазина: Ozon — `/ozon`
  (избранное по умолчанию), Randewoo — `/cart`. Для повторного входа Ozon — `/ozon/login`.
- Логотип дополняет эмодзи состояния и название магазина.
- `〈лого〉` в примерах ниже обозначает настоящий кастомный эмодзи магазина.

## Логотипы

- Набор: <https://t.me/addemoji/logos_td>.
- `custom_emoji_id`: `5463148170869482726`.
- Соответствующий обычный эмодзи набора: `😎` — резервное отображение Telegram.
- Кастомный эмодзи отправлен владельцу пробным сообщением, получение подтверждено.
- Использовать дополнительно во всех отчётах Ozon.

- Набор: <https://t.me/addemoji/pcheck>.
- `custom_emoji_id`: `5382276449241703317`.
- Соответствующий обычный эмодзи набора: `🌸` — резервное отображение Telegram.
- Статичный эмодзи размером 100 × 100 пикселей.
- Использовать дополнительно во всех отчётах Randewoo.

- [Файл для Telegram, 100 × 100](../assets/telegram/randewoo-emoji.png).
- [Исходник большего размера](../assets/telegram/randewoo-logo-source.png).

## Шаблоны отчётов

Одинаковые шаблоны применяются к обоим магазинам с заменой названия и логотипа.
Значения ниже условные. Кнопки отделены от текста сообщения.

### Есть изменения

```text
✅ 〈лого〉 Ozon · 19.10, 14:30 МСК

📉 Снижений: 12
📈 Повышений: 4
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.

### Изменений нет

```text
✅ 〈лого〉 Randewoo · 19.10, 15:00 МСК

Изменений цен нет.
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.
Этот итог допустим только после успешной проверки; ошибка не означает отсутствие изменений.

### Частичный результат

```text
⚠️ 〈лого〉 Ozon · 19.10, 15:30 МСК

Часть данных не удалось получить.

📉 Снижений: 5
📈 Повышений: 2
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.
Счётчики отражают только изменения, подтверждённые полученными данными.

### Ошибка

```text
🔴 〈лого〉 Ozon · 19.10, 16:00 МСК

Не удалось выполнить проверку.
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.

### Проверка прервана

```text
⏹ 〈лого〉 Randewoo · 19.10, 16:00 МСК

Проверка прервана.
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.

### Подтверждена потеря входа

```text
🔐 〈лого〉 Ozon · 19.10, 16:30 МСК

Требуется повторный вход в аккаунт.
```

Для Ozon кнопка: `🔐 Войти в Ozon` → защищённая страница `/ozon/login` на сайте.
Для Randewoo — кнопка перехода к подключению Randewoo в существующем интерфейсе.
Номер телефона, код входа и cookies не включать в сообщения.

### Первая успешная проверка после сбоя

```text
✅ 〈лого〉 Ozon · 19.10, 17:00 МСК

Проверка снова работает.

📉 Снижений: 3
📈 Повышений: 1
```

Кнопка: `🌐 Открыть сайт` → сайт Price Checker.
При отсутствии изменений вместо счётчиков использовать строку `Изменений цен нет.`.
Восстановление отмечать в первом успешном отчёте после сбоя.

### Задержка доставки

Добавить к соответствующему отчёту строку:

```text
🕒 Отчёт доставлен с задержкой.
```

В заголовке сохранить время самого сбора, а не время доставки.
Отметку добавлять, если от завершения сбора до отправки прошло больше пяти минут.

## Ответы на команды

- `/check`: показать выбор магазина.
- `/check_randewoo` и `/check_ozon`: короткое подтверждение запуска с названием
  магазина, например `▶️ Проверка Ozon запущена. Результат придёт после завершения.`
- Повторный запуск во время сбора: `⏳ Проверка уже выполняется.`
- `/status`: состояние каждого магазина, последний результат, ближайший запуск по МСК,
  включено ли расписание.
- `/start` и `/help`: назначение бота и основные команды.
- Во всех этих ответах тоже должна быть кнопка `🌐 Открыть сайт`.

## Повторные ошибки

Уведомлять при первом возникновении проблемы, при изменении причины и при
восстановлении. Избегать повторяющихся одинаковых уведомлений о сохраняющейся ошибке.

## Исходники и проверки

Реализация находится в `src/telegram.js`; подключение Ozon и уведомления о входе —
в `run.js`. `tests/telegram.test.js` проверяет очереди отчётов обоих магазинов,
правильные маршруты кнопок, повторные ошибки, восстановление и задержку доставки.

В Git сохранены также действующие серверные изменения Ozon, независимых расписаний
и отображения недоступности. Обычный CI/CD из `main` собирает их вместе с ботом;
применять отдельные серверные патчи при последующих выкладках не требуется.
