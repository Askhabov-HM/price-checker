# Вход владельца в Ozon на сервере

Страница `/ozon/login` открывает окно серверного Chrome внутри Price Checker. Доступ к странице и к WebSocket требует действующего входа в Price Checker. Номер хранится только в `.secrets/ozon/login.json`, в международном формате `+7` и десять цифр. Этот файл исключён из Git; на сервере он находится в `/var/lib/price-checker/secrets/ozon/login.json` с правами 0600.

Если HTTP или браузер возвращает 401 либо явно гостевой аккаунт, сбор останавливается, старые данные остаются. После закрытия браузера сборщика и освобождения его блокировки бот отправляет владельцу Telegram-ссылку на `/ozon/login`. Сам по себе 403 не доказывает потерю входа: сначала сохраняется переход к браузерному чтению. Другой аккаунт не подменяет существующий.

Окно запускается по кнопке «Открыть Ozon». Владелец нажимает «Войти» в самом Ozon, может подставить сохранённый номер кнопкой Price Checker, запрашивает код и вводит его непосредственно в Ozon. Приложение не читает и не сохраняет введённый код.

«Сохранить вход» читает избранное из этого браузера, подтверждает прежний аккаунт и переносит scoped cookies в приватную HTTP-сессию. Затем серверный Chrome закрывается и блокировка освобождается. Закрытие вкладки также отправляет запрос сохранения, но доставка такого запроса зависит от браузера и сети, поэтому основной путь — кнопка. Если вход не подтверждён, сессия не перезаписывается. Окно автоматически закрывается через 20 минут. Закрытие окна без подтверждённого входа не считается авторизацией.

Telegram использует существующего бота и настроенный `PRICE_CHECKER_TELEGRAM_OWNER_ID`; номер телефона не служит адресом Telegram. Уведомление не содержит cookies, номера, кода или пароля окна. Повторы при той же потребности ограничены одним сообщением за 30 минут. Браузер запускается только по открытию окна; ожидающее уведомление не держит Chrome в памяти.

## Установка

Нужны установленные Chrome, Xvfb, x11vnc, websockify, noVNC и существующий профиль `ozonbrowser`. По умолчанию файлы noVNC читаются из `/opt/price-checker-ozon-remote/extracted/usr/share/novnc`, Python-пакеты — из соответствующего `usr/lib/python3/dist-packages`. Для другого расположения статических файлов задаётся `PRICE_CHECKER_OZON_NOVNC_PATH` в окружении основного приложения. `PRICE_CHECKER_PUBLIC_ORIGIN` задаёт HTTPS-адрес в Telegram.

После установки релиза необходимо обновить `price-checker-ozon-recovery@.service`: новый лимит 1320 секунд позволяет выполнить интерактивный вход; обычное чтение по-прежнему ограничено 590 секундами внутри worker. Worker запускается тем же приватным Unix socket, от `ozonbrowser`, без прав root.

Для HTTPS virtual host nginx нужно подключить содержимое `scripts/nginx/ozon-login.conf` внутри блока `server`. Текущая общая директива `Connection ""` не пропускает WebSocket; для пути просмотра требуется отдельный `location` из этого файла. Остальные пути остаются под существующим проксированием приложения. Изменение исходников само по себе не меняет конфигурацию nginx или systemd.

VNC и websockify слушают случайные порты только на loopback. Доступ извне идёт через проверку сессии, Origin и временного ключа в основном приложении. Просмотр привязан к сессии Price Checker, создавшей окно. Выход из Price Checker закрывает её окно. На время входа удерживается общая блокировка сборщика: второй Chrome с тем же профилем параллельно не запускается.

Окно входа не включает расписание. После сохранения входа снимается требование действий; если расписание уже включено, следующий проход разрешается сразу после существующего явного ожидания источника.
