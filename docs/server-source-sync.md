Она содержит более ранние версии части модулей приложения. Её точное содержимое

рассчитаны для UTF-8 с окончаниями строк LF. Восстановление патча и совпадение всех
38 файлов проверены отдельно от рабочего приложения. Этот архивный патч не
предназначен для применения поверх актуального `main`.

`scripts/deploy.py` активного релиза: контрольные суммы совпали.

## Что создаётся на сервере

В Git не переносятся базы и их резервные копии, `.secrets`, `.data`, cookies,
персональные настройки входа, зависимости `node_modules`, собранный `dist`,
журналы и результаты запусков. Они относятся к данным и окружению установки.

Из предыдущего ручного релиза исключены только создаваемые выкладкой записи:
`REVISION`, `DEPLOYMENT.json`, `STOCK_BLUE_DEPLOYMENT.json`,
`STOCK_BLUE_MANIFEST.json`, `TELEGRAM_DEPLOYMENT.json` и
`TELEGRAM_LINKS_DEPLOYMENT.json`. Они описывают конкретные серверные выкладки,
а не отдельные изменения исходников.
