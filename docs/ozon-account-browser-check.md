# Ozon: аккаунтное чтение через сеть VDS

17 октября 2026, результат зафиксирован в 23:42 МСК (20:42 UTC). Отдельный worktree `price-checker-ozon-design`.

Обновление 18 октября: аналогичное аккаунтное чтение и немедленный перезапуск подтверждены уже непосредственно на Linux VDS после самостоятельного входа владельца в новый серверный профиль. См. [публичную карточку и вход на Linux](ozon-public-product-linux.md). Ниже сохранён предыдущий Windows-эксперимент.

## Результат

В отдельном Windows Chrome на компьютере владельца подтверждены авторизованное чтение избранного и корзины, выбранная доставка, цены одной карточки и продавец. Браузер использовал SOCKS-туннель через текущий VDS; перед входом проверено, что выходной IP совпадает с IP VDS. Владелец самостоятельно вошёл в аккаунт и выбрал адрес.

Чтение выполнено через Chrome DevTools MCP: GET к проверенному `/api/entrypoint-api.bx/page/json/v2` из того же браузерного контекста, затем сохранение настоящих ответов Network. Cookies не переносились в Node-клиент. Четыре явных диагностических GET получили HTTP 200 с JSON. Обычная загрузка страниц и фоновые запросы сайта в это число не входят.

| Проверка | Подтверждено |
| --- | --- |
| Аккаунт | ID совпадает с приватным эталоном; для избранного есть `isLoggedIn=true` |
| Доставка | Отпечаток выбранной местности и видимого адреса совпадает с эталоном в избранном, корзине и карточке |
| Избранное | Выбрана сортировка `last_added`; из 36 настоящих избранных первой страницы выделены последние 30, список полный для этого лимита |
| Цены в списке | У 23 из выбранных 30 есть цена; 7 недоступны. Отсутствующая цена не превращается в ноль |
| Корзина | 3 строки, по одной единице; количество и полнота сверены с `master.summary` |
| Одна доступная карточка | Подтверждён тот же SKU, обычная цена, отдельная цена Ozon Карты и числовой ID продавца |
| Условия карточной цены | Прочитан возвращённый карточкой список банков для того же SKU; наличие Ozon Банка подтверждено |

## Что ещё не подтверждено

Chrome работал на компьютере владельца, а VDS обеспечивал сетевой выход. Это подтверждает доступ к аккаунтным данным через IP VDS в данном браузерном окружении. Автономная работа Chrome на Linux VDS остаётся отдельной задачей: предыдущий Linux-профиль получал 403 до входа в аккаунт. Причина различия окружений не установлена.

В этом тесте не проверялись сохранение авторизации после перезапуска, срок жизни сессии, двухчасовое расписание, длительная стабильность и обе цены всех 30 товаров. Успех одного прохода не заменяет эти проверки. Предыдущий 403 серверного Node-клиента этим результатом не снят.

Следующий технический этап — воспроизвести браузерное аккаунтное чтение непосредственно на сервере, затем проверить восстановление того же аккаунта и доставки после перезапуска и несколько циклов расписания.

Последующая ограниченная проверка непосредственно на Linux VDS с русским языком, рабочим WebGL и cookies этого аккаунта снова получила 403, включая переход на выданную Ozon страницу проверки. Пик памяти Chrome с Xvfb около 427 МиБ не достиг лимита 768 МиБ; полный сбор товаров не был достигнут. Результаты — в [Linux-отчёте](ozon-linux-browser-check.md).

## Хранение и завершение

Запросы, ответы и разобранные данные сохранены только в игнорируемой `.secrets/ozon-server/account-browser-test/`. В этом документе нет cookies, ID аккаунта, точного адреса или перечня личных покупок. Постоянный тестовый профиль Chrome с выполненным входом сохранён приватно.

Тестовый браузер и SSH-туннель закрыты; порты 19226/19227 больше не слушают. Расписание Ozon не включалось. Рабочие базы и службы Randewoo не менялись.
