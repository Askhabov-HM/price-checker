# Защита SSH через Fail2ban

Шаблон `scripts/fail2ban/sshd.conf` включает защиту SSH на TCP-порту 22:
пять событий отказа по стандартному фильтру `sshd[mode=normal]` за десять минут
дают блокировку источника на час. Backend читает systemd journal; действие
`iptables-multiport` добавляет отдельную цепочку `f2b-sshd` для IPv4/IPv6.
UFW сохраняет свои правила. HTTP/HTTPS и исходящие соединения не блокируются
этим действием. Временные правила Fail2ban смотреть через iptables, не UFW.

Успешный вход по SSH-ключу и ошибка пароля `sudo` не считаются ошибкой SSH.
Обычный режим фильтра не блокирует корректного пользователя за предложение
неподходящего публичного ключа. Локальные подключения исключены, постоянного
списка доверенных внешних IP нет. При нескольких пользователях за одним
публичным IP блокировка источника относится ко всем их подключениям к SSH.

Установщик не меняет ключи, пользователей, `sshd_config`, VPN, расписания или
службу приложения. Отключение SSH-паролей настраивается отдельно и должно быть
проверено до установки. Для аварийного восстановления нужен доступ к консоли
хостинга; пароль root для неё сохраняется независимо от правил SSH.

## Установка

Запускать от root из чистого, сохранённого и отправленного серверного
`/opt/price-checker/repository`, ветка `develop`, upstream `origin/develop`.
Поддерживается Ubuntu 24.04, один SSH-порт 22. Установщик добавляет пакеты
`fail2ban` и `python3-systemd`; обновление индексов APT не обновляет остальные
установленные пакеты. Автоматические перезапуски сторонних служб через
needrestart при этой операции отключены.

Сначала сохранить текущую SSH-сессию и назначить автоматическую остановку
Fail2ban на случай потери нового подключения:

```sh
systemd-run --unit=price-checker-fail2ban-safety --on-active=5min /usr/bin/systemctl stop fail2ban.service
bash scripts/setup-fail2ban.sh
```

Установщик сохраняет прежний управляемый jail и состояние службы в приватном
`/var/backups/price-checker-fail2ban/install-*`, проверяет конфигурацию до
активации и возвращает прежний jail при ошибке. При первой установке временная
маска службы предотвращает преждевременный запуск пакетной конфигурации.
При повторном запуске настройки других jail сохраняются. Если служба ранее
была активна, применяется reload; обычный повторный запуск её не останавливает.

Проверить **новое внешнее SSH-подключение** с компьютера владельца. Затем
из этого нового подключения отменить страховочный таймер:

```sh
systemctl stop price-checker-fail2ban-safety.timer
fail2ban-client status sshd
```

Если таймер не отменить, примерно через пять минут защита остановится,
даже если установка успешна. Включение службы при следующей загрузке остаётся.
Не проверять защиту намеренным подбором пароля с IP владельца.

## Контроль и восстановление доступа

```sh
systemctl status fail2ban.service
fail2ban-client status sshd
journalctl -u fail2ban.service --since today
iptables -S f2b-sshd
ip6tables -S f2b-sshd
```

Цепочка для семейства адресов может появиться при первой блокировке.
Чтобы убрать ошибочную блокировку, выполнить из оставшейся сессии или консоли:

```sh
fail2ban-client set sshd unbanip CLIENT_IP
```

`CLIENT_IP` заменить внешним IP компьютера владельца. Для аварийного отключения:

```sh
systemctl disable --now fail2ban.service
```

Остановка штатно удаляет правила Fail2ban; настройки UFW и SSH остаются.
Ключи GitHub Actions и серверного Codex не менять. Любые дополнительные jail,
постоянные исключения адресов или увеличение времени блокировки — отдельная
настройка.

## Закрытие неиспользуемого UDP 443

`bash scripts/close-unused-https-udp.sh` от root заменяет общее правило
`ufw allow 443` отдельным разрешением `443/tcp`. Скрипт требует чистую,
сохранённую и отправленную ветку `develop` с upstream `origin/develop`,
активный UFW и отсутствие слушателя UDP 443.

Перед изменением сохраняются `/etc/ufw/user.rules`, `user6.rules` и перечень
правил в приватный `/var/backups/price-checker-firewall/https-443-*`.
Сначала разрешается и проверяется TCP 443 для обоих семейств адресов,
затем удаляется общее правило. При ошибке возвращается общее разрешение 443
для сохранения доступности HTTPS. Повторный запуск проверяет результат
без повторного изменения правил.

Остальные правила, включая TCP 22/80 и цепочки Fail2ban, не изменяются;
UFW не отключается и не перезагружается. Постоянные списки IP для SSH
этот скрипт не создаёт.
