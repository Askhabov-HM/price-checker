# Цены недоступных избранных товаров

Текущее правило: недоступные товары остаются в слежении. При каждом общем сборе читается всё избранное, включая товары со статусами `out_of_stock` и `unavailable`. Их возвращение определяется по новому ответу избранного, без отдельных запросов карточек и поисковых перенаправлений.

Пока товара нет в наличии, известная цена и её исходная дата сохраняются; при переходе в недоступное состояние остаётся последняя цена доступного товара. При отсутствии истории цена остаётся `null`. После возвращения автоматически сохраняется новая цена из избранного. Она сравнивается с последней известной ценой, в том числе сохранённой до возвращения; такая история больше не исключается из базы сравнения на сайте. Перенос старой цены на период отсутствия не создаёт нового изменения. Повторное получение той же цены после возвращения не сбрасывает отметку изменения.

Недоступность отмечается синим: цена и статус в таблице и истории, точки большого и маленьких графиков. В подсказке точки указано, что цена последняя известная; если цена неизвестна, синяя отметка наличия не обозначает нулевую цену. На период отсутствия линия прерывается. Ошибки сбора по-прежнему отмечаются красным.

Описанный ниже отдельный скрипт относится к ранее выполненному разовому получению цен и в последующие проходы не включается.

Обычный сбор избранного не открывает карточки. По отдельному явному запросу владельца можно запустить `scripts/ozon-unavailable-prices.js` в серверном runtime от пользователя `pricechecker`. Скрипт выбирает только сохранённые избранные со статусом `out_of_stock` или `unavailable`, удерживает общую блокировку сборщика и не включает расписание.

Для каждого выбранного SKU читается его API-карточка и проверенное перенаправление на поиск с тем же `product_id`. Поддерживается наблюдаемый параметр `page_changed=true`. Разрешены только HTTPS, origin `https://www.ozon.ru` и endpoint `/api/entrypoint-api.bx/page/json/v2`; редиректы на другой товар или другой origin не используются. Аккаунт проверяется по прежнему эталону. При ограничении доступа, потере авторизации или Retry-After проход останавливается.

Цена берётся из `webOutOfStock-*`: после разбора JSON виджета используется `price.price[].text` с `textStyle=PRICE`, при этом `price.priceStyle.styleType` должен быть `UNAVAILABLE`, а `common.action.link` — вести на исходный SKU. Цена рекомендаций в этом ответе не используется. Дополнительно поддержан `webPrice.price`, только если `webDetailSKU.copyText` подтверждает исходный SKU.

Найденная цена записывается в историю как `listed_price_kopecks`; недоступность сохраняется отдельным значением `availability`. Сообщение наблюдения содержит источник поля. Если цены в ответе нет, предыдущая известная цена не заменяется нулём: фиксируется неудачная попытка. Состав избранного и цены остальных товаров не меняются. Отдельный прогресс сохраняется в приватном `.secrets/ozon/unavailable-price-update.json`; неудачные ответы без цены — в `.secrets/ozon/unavailable-price-responses/` (0600). `--retry-errors` повторяет только позиции с ошибками из предыдущего отчёта.

Это отдельный явный запуск; автоматический вызов при обычном обновлении избранного не подключён. Основной релиз и CI данным скриптом не обновляются.
