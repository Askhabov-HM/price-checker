# Price Checker

Локальное приложение на **Node.js** для отслеживания цен Randewoo на варианты
**1,5 мл**. Работает без AI и платных API.

Repository: [Askhabov-HM/price-checker](https://github.com/Askhabov-HM/price-checker).

## Запуск

Требуются **Node.js 24.14.1 или новее**, npm и **curl** в PATH.
В Windows используется `curl.exe`. Python не нужен.

```powershell
npm ci
npm start
```

Приложение откроется в браузере: **http://127.0.0.1:8000**.
В терминале Ctrl+C завершает работу.

На Windows можно дважды нажать **start.cmd**: приложение запустится в фоне.
При первом запуске скрипт установит npm-зависимости, если они отсутствуют.
Закрытие вкладки браузера не останавливает сбор. Для остановки дважды нажмите
**stop.cmd**: сервер отметит активную проверку как прерванную, закроет базу
и освободит блокировку. Данные сохранятся.

```powershell
npm start -- --no-browser
npm start -- --no-browser --port 8001
```

Другой порт используется после остановки предыдущего экземпляра.

## Возможности

- Корзина и избранное аккаунта Randewoo, включая все страницы избранного.
- Независимый список «Наблюдение»: добавление ссылки или звёздочка у товара.
- Только варианты 1,5 мл. Разные концентрации имеют отдельные артикулы и историю.
- Текущая цена, изменение в рублях и процентах, минимум за историю, наличие.
- График каждого варианта за неделю, месяц, 90 дней или всё время.
- Обзор стоимости списка: по одному доступному пробнику каждого варианта.
  Это не итог заказа с учётом количества, доставки, баллов или промокодов.
- Поиск, сортировка, фильтры снижения/роста/минимума цены, экспорт CSV для Excel.
- Журнал проверок и ежедневная локальная резервная копия SQLite.

По умолчанию проверки выполняются в **00:30, 09:00, 14:00, 20:00 по Москве**.
Время можно изменить или поставить проверки на паузу в настройках. После сна
или перезапуска выполняется одна проверка за последний пропущенный интервал;
исторические цены за время выключения компьютера не восстанавливаются.

**Компьютер должен быть включён, подключён к интернету и не спать.**
Сбор работает, пока запущено приложение. Графики содержат реальные проверки:
при одной точке линия не выдумывается. Ошибки и недоступные варианты не становятся
нулевой ценой. Обзор явно указывает, сколько доступных позиций вошло в сумму.
При изменении состава набора линия прерывается, даже если число товаров прежнее.

В корзине можно переключить **публичную цену на сайте** и **цену варианта в
корзине аккаунта**. Эти истории хранятся отдельно. Основной тип цены — публичная
цена сайта. Удаление товара из списка сохраняет историю в базе.

## Авторизация

Сессия хранится локально в `.secrets/randewoo-session.json`:

```json
{
  "cookie": "<Cookie request header>",
  "user_agent": "<User-Agent request header>"
}
```

Значения берутся из своего запроса `/cart` в Chrome DevTools → Network.
Обновить их можно в настройках приложения. Они не возвращаются интерфейсу,
не выводятся в логи и не передаются curl через аргументы процесса: конфигурация
поступает через stdin. Сессия может истечь; приложение сообщит об этом и сохранит
списки. Публичные цены известных товаров продолжат проверяться без входа.

Сервер слушает только `127.0.0.1`. Изменения требуют токен текущей локальной
страницы. Веб-интерфейс не предоставляет доступ к файлам сессии, базе или исходникам.

## Данные и переход с Python

- `.data/prices.sqlite3` — общая база товаров, вариантов, списков и наблюдений.
- `.data/backups/` — резервные копии базы, по одной за день.
- `.data/imports/` — первоначальные реальные снимки для однократного импорта.
- `.secrets/` — действующая авторизация Randewoo.
- `scratch/` — временные результаты диагностических скриптов; можно удалять.

Эти каталоги исключены из Git. **Существующая база Python-версии используется
напрямую**: идентификаторы, история, настройки и авторизация сохраняются.
Формат UTC-времени и цены в целых копейках совместимы с прежней версией.
Первые реальные снимки из `.data/imports/` импортируются один раз при создании новой
базы; синтетические данные в рабочую базу не добавляются.

Перед переходом локально сохранена отдельная копия
`.data/migration-before-node.sqlite3`. Исходники Python-версии доступны в коммите
`b7d696c`. Для возврата сначала остановите Node.js; не запускайте два разных
сборщика с одной базой одновременно.

Локальный бэкап не защищает от поломки диска: для длительного хранения копируйте
его на другое устройство или в своё хранилище.

## Автозапуск Windows

При желании выполните один раз:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\enable-autostart.ps1
```

Создаётся или обновляется задача `PriceChecker-price-checker` текущего пользователя.
Она запускает `start.ps1 -NoBrowser` при входе в Windows. Node.js работает в фоне,
без открытия вкладки или окна консоли. Отключить автозапуск можно в Планировщике
заданий Windows. Если задача осталась от Python-версии, повторный запуск скрипта
обновит её команду.

## Проверки и обслуживание

```powershell
npm test
npm run check
```

Тесты используют временные базы и фикстуры, не обращаясь к реальному аккаунту.
Проверяются парсинг, пагинация, история и совместимость схемы, расписание,
авторизация, блокировка процессов, HTTP API, защита секретов и CSV.

Для настоящей разовой проверки остановите фоновое приложение и выполните:

```powershell
npm run collect
```

Повторный экземпляр блокируется. После аварийного завершения блокировка может
сохраняться до 10 секунд; подождите и повторите запуск. Незавершённая проверка
после перезапуска отмечается как прерванная и может быть повторена.

Диагностика без записи в рабочую базу:

```powershell
node scripts/probe-products.js https://randewoo.ru/product/alfred-dunhill-icon --output scratch/icon-node.json
node scripts/probe-cart.js --output scratch/cart-node.json
```

Логи фонового процесса: `.data/server.log`, `.data/server-error.log`.

## Структура

- `run.js` — запуск сервера, обработка остановки и блокировка экземпляра.
- `src/client.js` — HTTP-транспорт curl и разбор HTML через Cheerio.
- `src/database.js` — SQLite и совместимая схема данных.
- `src/service.js`, `src/time.js` — сбор, синхронизация списков и расписание.
- `src/web.js` — HTTP API и CSV.
- `public/` — интерфейс, без внешних CDN и сборки.
- `tests/` — тесты встроенного `node:test`.

Используется встроенный [node:sqlite](https://github.com/nodejs/node/blob/v24.14.1/doc/api/sqlite.md), который в проверенной Node.js 24.14.1
помечен как экспериментальный. Предупреждение в логах ожидаемо; API и совместимость
базы проверены тестами. npm-зависимости зафиксированы в `package-lock.json`.
