# Chrome для Lamoda на Windows

Запустите `launch-chrome.cmd` двойным щелчком. Нужны установленный Google Chrome и Node.js версии из корневого `package.json`. При необходимости задайте переменную `LAMODA_CHROME_PATH` с полным путём к `chrome.exe`.

Программа открывает `https://www.lamoda.ru/wishlist/` в обычном видимом Chrome. Его данные хранятся отдельно в `%LOCALAPPDATA%\PriceChecker\LamodaCollector\Chrome`. Первый вход в Lamoda выполните сами в открывшемся окне. Профиль `lamoda` внутри вашего повседневного Chrome и его ярлык программа не использует; cookies между профилями не копируются.

`launch-chrome.cmd` открывает браузер для входа и ручной проверки. При запуске браузер открывает страницу избранного и включает CDP только на `127.0.0.1` в этом отдельном профиле, но сам не собирает и не отправляет данные.

## Пробный снимок в отдельную таблицу

После развёртывания совместимой серверной версии откройте отдельную страницу **Lamoda · ПК** (`/lamoda/desktop`) и нажмите «Получить код подключения ПК». Запустите `pair-desktop.cmd` на ноутбуке и введите этот одноразовый код. Токен устройства хранится в `%LOCALAPPDATA%\PriceChecker\LamodaCollector\desktop-device.json` в виде DPAPI-шифротекста текущего пользователя Windows. Не переносите этот файл на другой компьютер и не добавляйте его в Git.

`collect-once.cmd` вручную читает все страницы избранного через CDP в отдельном Chrome, проверяет аккаунт и отправляет нормализованный снимок на VPS. Chrome должен разрешать удалённую отладку в своём отдельном профиле; если окно закрыто, сборщик попробует запустить Chrome с локальным временным CDP-портом. При открытом окне без CDP сбор завершится ошибкой и не станет закрывать рабочий Chrome. Если браузер открыт старой версией запускателя, закройте его и откройте новым `launch-chrome.cmd`.

Сервер записывает успешный снимок в отдельные `desktop_snapshots`, `desktop_products` и `desktop_observations`. Основные `products`, `observations`, `checks`, расписание Lamoda, Android и уведомления при таком запуске не меняются. На странице `/lamoda/desktop` показываются только данные ПК, включая график, товары и историю. Старый снимок индексируется при обновлении без повторного сбора.

## Автозапуск и пробное расписание

После обновления сервера запустите `install-autostart.cmd` под тем же пользователем Windows, под которым выполнено подключение ПК. Установщик создаёт задачу `PriceChecker-Lamoda-Desktop` с запуском при входе пользователя, без запрета работы от батареи, и запускает её сразу. Программа в фоне получает расписание с VPS; браузер открывается только для назначенного сбора. Обычный Chrome не закрывается. Задача не будит спящий ноутбук: для этого режима автоматический сон отключён отдельно в настройках Windows.

На странице **Lamoda · ПК** включите пробное расписание «Каждые 3 минуты». Отсчёт первого задания начинается после включения. VPS выдаёт одну актуальную работу, когда наступает срок, без очереди пропущенных запусков. Интервал действует, пока вы не нажмёте «Выключить каждые 3 минуты». Расписание основного сбора Lamoda и Android не меняется. Явный `Retry-After` останавливает новые попытки до указанного времени.

Состояние видно на странице ПК: последний контакт ноутбука, следующий срок, текущий сбор, снимки и ошибки. Локальный краткий журнал — `%LOCALAPPDATA%\PriceChecker\LamodaCollector\agent.log`; он ограничен 1 МБ. Для удаления только задачи автозапуска используйте `uninstall-autostart.cmd`. Отключение расписания на сайте прекращает новые сборы, но оставляет фоновую программу на связи.
