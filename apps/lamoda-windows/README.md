# Chrome для Lamoda на Windows

Запустите `launch-chrome.cmd` двойным щелчком. Нужны установленный Google Chrome и Node.js версии из корневого `package.json`. При необходимости задайте переменную `LAMODA_CHROME_PATH` с полным путём к `chrome.exe`.

Программа открывает `https://www.lamoda.ru/wishlist/` в обычном видимом Chrome. Его данные хранятся отдельно в `%LOCALAPPDATA%\PriceChecker\LamodaCollector\Chrome`. Первый вход в Lamoda выполните сами в открывшемся окне. Профиль `lamoda` внутри вашего повседневного Chrome и его ярлык программа не использует; cookies между профилями не копируются.

`launch-chrome.cmd` открывает браузер для входа и ручной проверки. При запуске браузер открывает страницу избранного, но этот запускатель не собирает и не отправляет данные.

## Пробный снимок в отдельную таблицу

После развёртывания совместимой серверной версии откройте раздел Lamoda в Price Checker и нажмите «Получить код подключения ПК». Запустите `pair-desktop.cmd` на ноутбуке и введите этот одноразовый код. Токен устройства хранится в `%LOCALAPPDATA%\PriceChecker\LamodaCollector\desktop-device.json` в виде DPAPI-шифротекста текущего пользователя Windows. Не переносите этот файл на другой компьютер и не добавляйте его в Git.

`collect-once.cmd` вручную читает все страницы избранного через CDP в отдельном Chrome, проверяет аккаунт и отправляет нормализованный снимок на VPS. Chrome должен разрешать удалённую отладку в своём отдельном профиле; если окно закрыто, сборщик попробует запустить Chrome с локальным временным CDP-портом. При открытом окне без CDP сбор завершится ошибкой и не станет закрывать рабочий Chrome.

Сервер записывает успешный снимок только в `desktop_snapshots`. Основные `products`, `observations`, `checks`, расписание, Android и уведомления при таком запуске не меняются. Автоматическое получение заданий и пробуждение ноутбука ещё не включены.
