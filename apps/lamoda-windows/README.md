# Lamoda на Windows

Запустите `launch-chrome.cmd`. Программа открывает одну вкладку
`https://www.lamoda.ru/wishlist/` в установленном Google Chrome и сразу завершается.
Вкладка остаётся открытой. Старый ярлык `collect-once.cmd` делает то же самое.

Используется отдельный постоянный профиль
`%LOCALAPPDATA%\PriceChecker\LamodaCollector\Chrome`. Вход в Lamoda в этом
профиле выполняет владелец. Обычный профиль Chrome не меняется. При необходимости
можно указать полный путь к `chrome.exe` через `LAMODA_CHROME_PATH`.

Программа не включает удалённую отладку, не читает страницу, не собирает товары
и цены, не прокручивает сайт и не обращается к Price Checker или его серверу.
Chrome выполняет обычную загрузку страницы и её ресурсов.

Автозапуск не требуется. Если владелец отдельно запустит `install-autostart.cmd`,
Windows будет открывать одну вкладку при входе пользователя. Задача не работает
в фоне и не повторяет открытие по расписанию. `uninstall-autostart.cmd` удаляет её.

Прежняя история ПК на странице `/lamoda/desktop` остаётся доступной для чтения;
этот запускатель её не пополняет.
