# Lamoda Collector для Android

Отдельное приложение для личного телефона владельца Price Checker. Android 8.0+
с обновлённым Android System WebView.
Встроенный WebView хранит вход Lamoda на телефоне. При открытии приложение
само открывает избранное и начинает сбор:
читает все страницы избранного и отправляет только поля товаров и подтверждение
аккаунта. Сервер проверяет весь список перед сохранением цен в базу Lamoda.

## Установить APK

1. Возьмите `app/build/outputs/apk/debug/app-debug.apk` из этой папки. Также APK
   доступен в ZIP-артефакте `lamoda-collector-debug` успешного GitHub Actions.
2. Передайте APK на телефон по USB или отправьте себе в Telegram как файл.
3. Откройте APK на телефоне. При запросе Android разрешите установку из этого
   источника для приложения, которым открываете файл, и нажмите «Установить».
4. Запустите **Lamoda Collector**. Root, SMS, контакты, Accessibility и USB-отладка
   для работы не нужны.

Это debug-сборка для личной проверки. Для обновления без удаления нужна та же
подпись APK. Локальная и CI-сборка могут иметь разные debug-подписи; у CI подпись
может меняться и между запусками. Для обновлений без переустановки используйте
локальные сборки на одном ПК с сохранённым debug-ключом. Удаление приложения
удаляет сохранённый вход и токен телефона.

## Подключить сервер

Серверная часть соответствующего PR должна попасть в `main` и пройти деплой.
До этого WebView открывается, но подключение по новой ссылке недоступно.

1. В личном Telegram-боте Price Checker выберите **Подключить телефон для Lamoda**
   (`/lamoda_android`). Бот выдаёт эту ссылку только владельцу в личном чате.
2. На телефоне нажмите **Подключить телефон**, затем кнопку запуска приложения.
   Если Telegram блокирует переход, выберите в меню **Открыть в браузере**.
   Код и адрес вручную вводить не нужно. Ссылка одноразовая, действует 10 минут
   и заменяет прежнее подключение телефона; не пересылайте её.
3. Альтернатива: откройте на телефоне `https://153.76.171.172/lamoda/android`,
   войдите в Price Checker и нажмите **Подготовить подключение → Подключить этот Android**.
4. Войдите в аккаунт Lamoda внутри приложения. Это отдельный вход от Chrome
   и встроенного браузера Telegram.
5. Сбор начинается автоматически после открытия приложения и загрузки страницы.
   После входа или капчи и перехода на страницу он продолжится автоматически.
   Если Lamoda вошла без перехода, нажмите **Собрать сейчас**. Оставьте приложение
   открытым до подтверждения отправки. Результат придёт через существующего бота.
   Вход сохраняется между запусками и обновлениями APK с той же подписью;
   повторный вход нужен, если Lamoda завершит сессию. SMS-код при входе,
   если его требует сама Lamoda, вводится только на странице Lamoda.
6. После первого успешного сбора включите расписание в разделе Lamoda, если
   нужны регулярные проверки. Telegram будет присылать кнопку **Открыть на Android**.
   Она ведёт на страницу запуска приложения. Если Telegram блокирует переход,
   выберите «Открыть в браузере» либо запустите приложение с экрана телефона:
   оно само начнёт проверку. «Задание» — внутреннее название проверки на сервере;
   пользователю создавать или выбирать его не нужно. При отсутствии ожидающей
   проверки приложение запускает ручное обновление избранного.

Подключение переключает только сбор Lamoda на телефон. Расписания остальных
магазинов не меняются. Отключение телефона на сайте отзывает токен и отменяет
текущий сбор. После отключения возвращается прежний серверный транспорт Lamoda;
для полной остановки проверок выключите также её расписание.

## Ограничения

- Приложение работает с открытым окном; фоновые запуски и заблокированный экран
  не используются. Во время сбора экран поддерживается включённым.
- Капчу проходит владелец. Работа Lamoda в WebView ещё должна быть проверена
  на реальном телефоне. Парсер поддерживает наблюдавшийся формат `__NUXT__`;
  другая разметка вызывает ошибку без изменения сохранённых цен.
- Читается только `/wishlist/?page=N`, без обхода карточек, корзины и заказов.
  Отправляются все страницы, максимум 1000. При изменении аккаунта или состава
  списка посреди сбора неполный результат не сохраняется.
- Для объединённых предложений Lamoda передаются `adjacent_skus` избранного и
  `hybrid_products` карточки. Сервер сопоставляет разные артикулы только при
  однозначной взаимной связи в этих полях. История сохраняется по исходному
  артикулу избранного; ссылка ведёт на карточку, из которой получена цена.
- На проверку отводится 45 минут. При перезапуске сервера она отменяется,
  повторный сбор начинается кнопкой **Собрать сейчас**. Повторная одинаковая
  отправка страницы допустима; ошибку сети можно повторить той же кнопкой. `Retry-After` соблюдается
  серверным планировщиком.
- Cookies Lamoda и пароль остаются в приватных данных приложения. Токен
  телефона зашифрован Android Keystore; на сервере хранится только SHA-256.
  Native JavaScript bridge не используется; токен недоступен странице Lamoda.
  Резервное копирование данных Android-приложения отключено.
- Для текущего сервера с собственным сертификатом сборка содержит его публичный
  SHA-256 в `app/build.gradle`. Проверка TLS не отключена. При смене сертификата
  обновите fingerprint и пересоберите APK. Другие серверы требуют обычный
  доверенный HTTPS-сертификат.

## Серверная часть

Код: `src/providers/lamoda/mobile.js`, API `/api/lamoda-mobile/*`, страница
`/lamoda/android`, существующие планировщик и Telegram-бот. Новые таблицы
находятся только в SQLite Lamoda и включаются в её существующие бэкапы.
Миграция добавляет таблицы без удаления истории.

Лимит страницы — 2 МиБ, нормализованных данных задания — 32 МиБ. Для Nginx на
текущем сервере выполните `sudo python3 /opt/price-checker/current/scripts/setup-lamoda-mobile.py`.
Установщик добавляет только мобильный маршрут, проверяет `nginx -t`, применяет
reload и сохраняет предыдущие файлы для восстановления. Остальные лимиты
остаются прежними. Исходный шаблон: `scripts/nginx/lamoda-mobile.conf`.
Без этого прежний общий лимит Nginx 100 КБ может отклонять большие страницы.
Bearer-токен телефона разрешает
только мобильный API; создание ссылки на сайте и отзыв требуют входа владельца
и CSRF, в Telegram — сообщения владельца в личном чате. Одноразовый секрет ссылки
передаётся в URL fragment, не попадает в HTTP query/access log и автоматически
обменивается приложением на токен. Адрес VPS не принимается из внешней ссылки.
У уже подключённого телефона токен сохраняется, повторная привязка не нужна.

## Сборка

Нужны JDK 17+, Android SDK 36, Build Tools 35.0.0. SDK задаётся через
`ANDROID_HOME` или локальный `local.properties` с `sdk.dir` (не коммитится).

```powershell
cd apps/lamoda-android
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Linux/macOS: `bash ./gradlew assembleDebug testDebugUnitTest lintDebug`.
Gradle 8.13 загружается wrapper-ом с проверкой опубликованного SHA-256.
CI выполняет сборку, JVM unit-тесты и lint. Эмуляторы, instrumentation,
e2e и тесты с реальным браузером не запускаются.
